# راهنمای فارسی HashGuard

[بازگشت به README اصلی](../README.md)

HashGuard یک ربات شخصی تلگرام برای ساخت هش امن پسورد، تولید checksum و بررسی پسورد با هش
Argon2id است. رابط ربات دکمه‌ای است و نتیجه را همراه دکمه‌ی Copy نمایش می‌دهد.

## امکانات

- هش پسورد با Argon2id و salt تصادفی
- SHA-256 برای checksum داده‌های غیررمزی
- بررسی مطابقت پسورد با یک هش Argon2
- حذف پیام ورودی بعد از دریافت
- فعالیت فقط در چت خصوصی
- محدودسازی دسترسی با Telegram ID
- عدم ذخیره‌ی ورودی‌ها در فایل یا دیتابیس
- اجرای مستقیم، Docker و کنترل کیفیت خودکار در GitHub Actions

## راه‌اندازی در ویندوز

### ساخت ربات

1. ربات رسمی [BotFather](https://t.me/BotFather) را باز کن.
2. دستور `/newbot` را بفرست.
3. نام و username را انتخاب کن؛ username باید به `bot` ختم شود.
4. token دریافتی را مثل پسورد محرمانه نگه دار.
5. با `/setjoingroups` اجازه‌ی اضافه‌شدن ربات به گروه‌ها را غیرفعال کن.

### نصب

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

فایل `.env` را باز کن و token را قرار بده:

```dotenv
TELEGRAM_BOT_TOKEN=توکن_ربات
ALLOWED_USER_IDS=
DELETE_INPUT_MESSAGES=true
MAX_INPUT_LENGTH=4096
```

ربات را اجرا کن:

```powershell
hashguard
```

در تلگرام `/id` بفرست. ربات شناسه‌ی عددی حسابت را نشان می‌دهد. برنامه را با `Ctrl+C` ببند،
شناسه را در `ALLOWED_USER_IDS` قرار بده و دوباره اجرا کن:

```dotenv
ALLOWED_USER_IDS=123456789
```

تا وقتی این فهرست خالی است، ابزارهای هش قفل می‌مانند و فقط مسیر دریافت ID فعال است.

## انتخاب الگوریتم

| نیاز | انتخاب درست |
|---|---|
| ذخیره‌ی پسورد در دیتابیس | Argon2id |
| checksum یا تشخیص تغییر فایل/داده | SHA-256 |
| بازیابی متن اصلی در آینده | هیچ‌کدام؛ به رمزنگاری نیاز داری |

هر بار هش‌کردن یک پسورد با Argon2id خروجی متفاوتی می‌دهد. این رفتار درست است، چون salt تصادفی
داخل خود رشته‌ی خروجی ذخیره می‌شود. برای ورود کاربر باید از تابع `verify` استفاده کنی، نه اینکه
پسورد را دوباره هش و دو رشته را با `==` مقایسه کنی.

## نکته‌ی امنیتی

فایل `.env` توسط Git نادیده گرفته می‌شود، اما خودت هم هرگز token را در issue، screenshot یا
commit قرار نده. حذف پیام به معنی نرسیدن آن به تلگرام نیست؛ برای پسورد واقعی production، هش را
داخل backend برنامه انجام بده.
